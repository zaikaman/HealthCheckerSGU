# CONTRIBUTING
We welcome contributions to HealthCheckerSGU. Please follow these guidelines to ensure smooth collaboration.

## How to contribute
- Fork the repository and create a feature branch from master
- Make changes with surgical edits and descriptive commits
- Run tests (if present) and ensure they pass
- Open a pull request against master with a clear description and linked issue

## Setup for new contributors
- Clone your fork: git clone https://github.com/your-username/HealthCheckerSGU.git
- Install dependencies: pip install -r requirements.txt
- Copy example env: cp .env.example .env and fill in required keys
- Run locally: python app.py (or as per project start command)
- Ensure tests pass (if tests exist)
